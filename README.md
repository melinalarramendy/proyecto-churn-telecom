# 📞 Customer Churn Prediction - Telecom

## 📋 Descripción del Proyecto
Predicción de abandono de clientes (churn) en una compañía de telecomunicaciones utilizando técnicas de Machine Learning.

## 🎯 Objetivo
Identificar proactivamente a los clientes con mayor probabilidad de cancelar su servicio para implementar estrategias de retención efectivas.

---

## 📊 Dataset
- **Fuente:** Kaggle - Telco Customer Churn
- **Registros:** 7,043 clientes
- **Variables:** 21 columnas (demográficas, servicios, contratos, facturación)
- **Target:** Churn (Yes/No)

## 🛠️ Tecnologías
- Python 3.9+
- Pandas, NumPy
- Scikit-learn, XGBoost
- Matplotlib, Seaborn
- Jupyter Notebook

## 📁 Estructura del Proyecto
```bash
proyecto-churn-telecom/
├── data/ # Datasets
├── notebooks/ # Jupyter notebooks
├── src/ # Código fuente Python
├── models/ # Modelos entrenados
└── reports/ # Reportes y visualizaciones
```

## 🚀 Cómo Ejecutar
1. Clonar repositorio
2. Crear entorno virtual: `python -m venv venv`
3. Activar entorno: `venv\Scripts\activate` (Windows) o `source venv/bin/activate` (Mac/Linux)
4. Instalar dependencias: `pip install -r requirements.txt`
5. Ejecutar notebooks en orden numérico
